Acuitey Solutions LMS — Moodle Extension Architecture

Structural isolation contract showing strict adherence to Moodle native extension hooks without core modification.

100% Core Preservation
All custom logic resides under /local/acuitey. Moodle core PHP files, lib files, and database schemas remain strictly vanilla.
Native Event Dispatch
Custom events extend \core\event\base, allowing core Moodle log readers, reporting tools, and external services to observe routing events natively.
XMLDB Compliance
Custom tables are generated through Moodle's XMLDB schema engine, providing automatic cross-database portability across PostgreSQL and MySQL.
