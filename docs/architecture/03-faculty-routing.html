Acuitey Solutions LMS — Automated "Ola/Uber-Style" Faculty Routing Engine

Multi-criteria constraint satisfaction, dynamic scoring algorithm, automated assignment, and resilient fallback queuing.

Continuous Workload Balancing
Prevents faculty burnout by checking active student loads and day caps before inclusion in the eligible allocation pool.
Non-Blocking Concurrency
Uses database row locks to guarantee zero double-allocations during peak request bursts across concurrent sessions.
Resilient Fallback Queuing
Zero dropped student requests. If all eligible faculty are occupied, requests queue gracefully for scheduled automated retries.
