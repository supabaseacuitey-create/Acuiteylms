Acuitey Solutions LMS — High-Level System Architecture

End-to-end component topology distinguishing vanilla Moodle Core from Acuitey custom extension services.

Clean Boundary Separation
Zero core file modifications. Upgrades to future Moodle LTS versions remain strictly plug-and-play without regression risks.
High-Throughput Routing
The routing engine executes within PHP-FPM for instant assignments, delegating batch retries to Moodle's native CLI task runner.
Security & Isolation
Database transactions are handled over TLS, payment signatures verify server-side, and live sessions authenticate via OAuth 2.0 LTI tokens.
