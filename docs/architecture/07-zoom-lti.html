Architecture Diagram 07

Zoom LTI 1.3 Advantage Integration

Standardized OpenID Connect (OIDC) authentication handshake and OAuth2 JWT authorization linking Moodle Course Contexts with Zoom LTI Pro without exposing Zoom Master API credentials to students.

Zero Passwords & Key Exposure
Using standard LTI 1.3 Advantage (IMS Global), students and faculty never handle meeting passwords or direct Zoom account credentials. Access is cryptographically signed using asymmetric RSA keypairs.
Moodle Course Context Binding
Sessions are tightly scoped to Moodle course contexts (context_course). Only enrolled students can initiate the LTI launch, eliminating "Zoombombing" or unauthorized external entries.
Grade & Attendance Sync
Grade and attendance synchronization may be enabled where supported by the selected Zoom LTI configuration and Acuitey’s Zoom account/licensing using LTI Assignment and Grade Services (AGS).
