| `marginBottom` | `number`                                                                                          | -        |
| `address`      | `string`                                                                                          | -        |
| `phone`        | `string`                                                                                          | -        |
| `email`        | `string`                                                                                          | -        |
| `logo`         | `ReactNode`                                                                                       | -        |
