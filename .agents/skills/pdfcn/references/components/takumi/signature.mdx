## Usage

```tsx

```

```tsx
<PdfSignatureBlock name="Jane Doe" label="Authorized Signature" />
```

## API Reference

### PdfSignatureBlock

| Prop      | Type                                 | Default    |
| --------- | ------------------------------------ | ---------- |
| `variant` | `'single' \| 'double' \| 'inline'`   | `'single'` |
| `label`   | `string`                             | -          |
| `name`    | `string`                             | -          |
| `title`   | `string`                             | -          |
| `date`    | `string`                             | -          |
| `signers` | `[SignatureSigner, SignatureSigner]` | -          |
| `style`   | `Style`                              | -          |
